Arcade · Phaser · Play in Browser

A Simpsons-inspired arcade game built in Phaser 3. You aim and fire a cannon at moving targets across escalating levels. It's small and silly, but it's fully playable in the browser right now — no install, no setup.

▶ Play Now GitHub
ENGINE
Phaser 3 / JS
PLATFORM
Web Browser
GENRE
Arcade / Score Attack

// CANNON ARCADE ACTION

Technical Breakdown

  • Cannon Trajectory — Matter.js handles arc physics, bounces, and collisions. Getting the shot prediction to feel satisfying without being too easy was most of the tuning work.
  • Difficulty Scaling — Targets move faster and patterns get more complex as you progress. Local high score tracking gives you something to chase each run.
  • Deployed on GitHub Pages — Fully browser-based, no install needed. Works on desktop and mobile — you can play it right now from the link above.
