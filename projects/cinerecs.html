CineRecs

Next.js 14 · Gemini API · Tailwind CSS

A movie recommendation engine that actually knows what you've already seen. Connect your Letterboxd account, export your watch history, and the app cross-references Gemini's suggestions against your existing watchlist so you don't get recommended films you've already rated. Built with Next.js 14, the Gemini API, and real-time poster/metadata from TMDB.

Technical Breakdown

  • Gemini-Powered Recs — User-defined parameters — genres, mood, era — get passed to the Gemini API to generate a tailored recommendation list. Prompt engineering handles edge cases like obscure preferences and conflicting filters.
  • Letterboxd Import Pipeline — Users upload their Letterboxd CSV export. JSZip parses it client-side, and custom filtering logic removes any recommended films that already appear in the user's watch history or watchlist.
  • Live Metadata & Posters — Every recommendation pulls real-time poster art and metadata from the TMDB API. Framer Motion handles the transitions — the goal was for results to feel like browsing a real streaming service, not a list.
