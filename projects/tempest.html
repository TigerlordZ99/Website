Tempest

2D Platformer · Unity / C#

A 2D platformer built around momentum — you don't stop unless you choose to. The character controller uses raycasting and a custom physics system to handle state transitions cleanly, so wall slides, ledge grabs, and mid-air direction changes all feel consistent. Levels are designed to teach the movement system before putting it under pressure.

Technical Breakdown

  • Momentum Controller — Custom character controller built around velocity preservation. Stopping is an active choice — the player carries speed through jumps, wall slides, and direction changes.
  • Level Structure — Levels introduce one mechanic at a time in a low-stakes context, then test it for real a few screens later. It's a pretty classic structure but it works well for movement games.
  • Dynamic Obstacles — Raycasting drives a flexible obstacle system — moving platforms, pressure triggers, and interactive objects all use the same underlying logic to keep the codebase clean.
