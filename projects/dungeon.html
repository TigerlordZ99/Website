Dungeon
Escape

Roguelike · Unity / C#

A Unity roguelike with procedurally generated maps and a modular weapon system. No two runs look the same — the dungeon layout is generated from a BSP tree, and weapons are built from stackable ScriptableObject modifiers so builds emerge naturally rather than being predetermined. Custom A* handles enemy pathfinding.

Technical Breakdown

  • Procedural Maps — BSP tree splits the space, then handcrafted room prefabs get placed and connected with generated corridors. Gives each run real structure without feeling completely random.
  • Modular Weapon System — Weapons are built from ScriptableObject modifiers that stack on each other. The goal was for players to find combinations that felt like their own discovery rather than something we put there.
  • Enemy Pathfinding — Custom A* tuned for tile-based layouts, with dynamic recalculation when obstacles move. Enemies share awareness — if one sees you, others start closing in.
